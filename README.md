♟️ My Custom Chess App
Hey there! 👋 Welcome to my own variation of chess.

Just to give credit where it's due: I didn't build the frontend entirely from scratch. 
I actually copied the base code from shenmareparas/chess because I really loved the style 
and feel of it. Huge shoutout to them for the awesome foundation!

Right now, I'm actively working on developing it further. 
My main focus is integrating more chess engines behind the scenes to create bots
that play with much more human-like moves, rather than just calculating like cold, perfect machines.

Stay tuned for what's coming in the future! 🚀
